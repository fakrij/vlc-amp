Which file name? Keep the name Titlebar-100.vlt. The Titlebar Setup (Install.cmd / Linux setup) picks the skin file by display scaling: Titlebar-100.vlt, Titlebar-125.vlt, Titlebar-150.vlt or Titlebar-200.vlt. To use your build, copy it over the file with the same name in the skin folder (%LOCALAPPDATA%\Titlebar-VLC-skin on Windows) and run Setup again, or choose it in VLC under Tools, Preferences, Interface, Use custom skin.

Only the Titlebar skin's own colours are changed; everything else comes from the generator. Fonts are shipped inside the .vlt with their licence text. All offered fonts are monospaced, so the time does not jitter.
